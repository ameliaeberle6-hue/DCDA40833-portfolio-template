Reflection — Data Preparation, Design, and Findings

This project used the hometown_locations - Sheet1.csv dataset: a list of places from my hometown with names, addresses, category/type, short personal descriptions, and image URLs. The dataset is primarily categorical and textual; there are no native numeric measures, and the fields require a bit of cleanup before a smooth Tableau Public import.

Data Preparation Challenges

The CSV contained inconsistent quoting and delimiter placement which prevents reliable parsing by Tableau. Some rows had mis-placed quote characters, missing commas before the image URL, and inconsistent use of whitespace. Category labels had inconsistent capitalization (e.g., "Cultural" vs " Cultural"). Addresses include commas inside the field which is fine if quoting is correct, but in this file the quotes are inconsistent. Because Tableau expects a well-formed CSV or Excel file, I cleaned the file by: (1) normalizing quotes; (2) ensuring five columns with headers: Name, Address, Category, Description, ImageURL; (3) trimming whitespace and fixing obvious typos; (4) optionally adding Latitude and Longitude columns by geocoding addresses for reliable mapping in Tableau.

Design Choices and Reasoning

For this dataset I focused on two complementary visualization approaches: a symbol map and a category-count bar chart. The symbol map (using geocoded coordinates or Tableau's built-in geocoding if you extract City/State/Zip) best reveals spatial clustering, showing where parks, restaurants, and cultural sites concentrate. The bar chart of counts per category (Restaurant, Park, Historical, Cultural, School, Recreation) quickly surfaces dominant types and helps spot underrepresented categories. I also used short description length as a small numeric proxy (description word count) to highlight unusually long or short entries — useful to flag outliers or entries that might contain multiple locations mashed together.

Expected Patterns

I expected restaurants and cultural locations to cluster around downtown Roswell (Canton St), parks to be more spread out near green spaces and the river, and historical sites to be near the Roswell Mill area. I also expected duplicate or near-duplicate addresses for sites that share the same location (e.g., Roswell Mill and Old Mill Park both listing 95 Mill St).

Surprises and Outliers

Malformed rows and missing commas were the biggest surprise — these are not data insights but data-quality obstacles. In the cleaned visualization, outliers to look for include locations geocoded outside the expected city bounds (signaling an address parsing problem), categories with a single item, or descriptions that include extra URLs stuck to text (those indicate missing separators).

Questions for Further Investigation

  • Why do some categories cluster more than others?
  • Are certain types of places (e.g., parks) consistently located near rivers or trails?
  • Do description sentiments vary by category (could do a simple sentiment score on descriptions)?

Evaluation of Tableau Public

Tableau Public excels at quick spatial and categorical exploration with minimal code; it provides strong mapping and drag-and-drop chart building, which is ideal for this dataset. Limitations: sensitive to malformed CSVs, less flexible for advanced text-cleaning (preprocessing outside Tableau is recommended), and requires careful geocoding for precise mapping if addresses are full street addresses. Overall, Tableau Public is excellent for rapid prototyping and sharing interactive visuals for a portfolio.
